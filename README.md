# Uncanny Office — downloads

Installers for Uncanny Office: a desktop app for your Claude Code sessions — terminals, a
pixel-art office where every session is a worker at a desk, and scheduled jobs.

Get the latest version from [Releases](../../releases/latest):

- **macOS:** `Uncanny.Office_<version>_aarch64.dmg` (Apple silicon; signed and notarised)
- **Windows:** `Uncanny.Office_<version>_x64-setup.exe` or `.msi`
- **Linux:** `.AppImage`, `.deb` (Debian/Ubuntu) or `.rpm` (Fedora)

The app updates itself from here. You need [Claude Code](https://docs.claude.com/en/docs/claude-code/overview);
the app can install it for you on first run.

Uncanny Office is an independent app and is not made by or affiliated with Anthropic.
